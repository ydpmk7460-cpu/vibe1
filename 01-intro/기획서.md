# 기획서: 자기소개 웹페이지

## 누가 쓰나

수업에서 처음 만난 친구들

## 만들 것

가상의 인물을 소개하는 한 페이지짜리 웹페이지

## 페이지 이름

**한도토리의 냥냥한 첫인사**

- 별명 `한도토리`와 귀여운 고양이 말투를 결합해 기억하기 쉽게 만든 이름
- 처음 만난 친구들에게 페르시안 친칠라처럼 포근하고 친근한 첫인상을 전달한다는 뜻

## 가상 인물 설정

- 이름(별명): 한도토리
- 나이: 22세
- 전공: 미디어콘텐츠학과 2학년
- 성격: 처음에는 조금 조용하지만, 친해지면 이야기를 많이 하는 편
- 취미: 사진 찍기, 농구 경기 보기, 카페 탐방
- 좋아하는 것: 고양이, 떡볶이, 인디 음악
- 가장 좋아하는 고양이: 은빛 털과 초록빛 눈이 매력적인 페르시안 친칠라
- 잘하는 것: 사진 보정, 발표 자료 꾸미기
- 대학 생활 목표: 새로운 친구들과 다양한 활동을 경험하기
- 한 줄 소개: 사진과 카페, 고양이를 좋아하는 미디어콘텐츠학과 2학년 한도토리입니다.
- 한마디: “아직 어색하지만 편하게 말 걸어 주세요! 맛집이나 좋은 카페를 함께 찾아다니고 싶어요.”

## 인사말

**“아직 어색하지만 편하게 말 걸어 주세요! 맛집이나 좋은 카페를 함께 찾아다니고 싶어요.”**

조용하지만 새로운 친구와 친해지고 싶은 한도토리의 성격과 카페 탐방 취미를 함께 전달한다.

## 기능

1. 별명 `한도토리`와 한 줄 소개
2. 전공, 성격, 취미 3가지, 좋아하는 것 3가지, 잘하는 것, 대학 생활 목표 소개
3. 버튼을 누르면 배경색이 바뀜

## 디자인

- 디자인 주제: 귀여운 페르시안 친칠라 고양이
- 전체 분위기: 포근하고 사랑스러우며, 처음 보는 사람도 부담 없이 읽을 수 있는 분위기
- 화면 구성: 고양이 장식을 포인트로 사용하되 내용에 집중할 수 있도록 심플하고 깔끔하게 구성
- 주요 색상: 페르시안 친칠라의 은빛 털을 닮은 밝은 회색, 초록빛 눈을 닮은 민트색, 부드러운 하늘색
- 기본 배경색: 따뜻한 크림색
- 배경색 변경: 버튼을 누를 때 연한 하늘색, 연한 민트색, 크림색 순서로 변경
- 글자 색상: 편안하게 읽을 수 있는 짙은 청회색
- 구성 요소: 고양이 귀 모양, 발바닥 무늬, 둥근 모서리와 넉넉한 여백으로 귀여운 느낌 표현
- 고양이 표현 방식: 제공된 실제 고양이 사진을 소개 영역에 사용
- 사진 주소: `https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcTzU7a2AZOFcm79rc0Zy_4V_Wgng7jauu_Y4st0yXdhHA&s=10`
- 색상은 글자를 읽기 어렵게 만들 정도로 진하게 사용하지 않음

## 조건

- `index.html` 파일 하나에 HTML, CSS, JavaScript만 사용
- 외부 라이브러리, 서버, 데이터베이스는 사용하지 않음
- 실명과 연락처는 넣지 않음
- 외부 이미지는 위에 적힌 고양이 사진 주소만 사용
- 인터넷에 연결되어 있지 않으면 고양이 사진이 표시되지 않을 수 있음
- 누가 봐도 가상임을 알 수 있는 인물 정보만 사용
- 화면에 표시되는 문구와 코드 주석은 한국어로 작성
- 페이지 이름과 인사말은 정해진 문구를 그대로 사용

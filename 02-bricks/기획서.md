# 냥냥 벽돌깨기 게임 기획서

## 1. 프로젝트 개요

- **프로젝트명:** 냥냥 간식 대작전
- **목표:** 고양이가 공을 튕겨 7층의 벽돌을 부수고, 떨어지는 먹이를 먹어 포만도 100을 채우는 웹 벽돌깨기 게임을 만든다.
- **대상 환경:** 1024 × 768 해상도의 데스크톱 모니터
- **개발 방식:** 별도의 설치 없이 웹 브라우저에서 실행되는 HTML, CSS, 순수 JavaScript 게임
- **저장 위치:** `02-bricks/`

## 2. 핵심 콘셉트

- 전체 화면은 밝은 파스텔 색상의 귀여운 고양이 테마로 꾸민다.
- 화면 아래쪽의 고양이가 좌우로 달리며 공을 몸으로 튕겨 낸다.
- 벽돌 안에는 사료, 츄르, 간식 중 하나가 들어 있다.
- 벽돌을 부수면 해당 먹이가 아래로 떨어지고, 고양이가 받아먹으면 포만도가 오른다.
- 포만도가 100이 되면 고양이가 배부른 상태가 되어 게임에서 승리한다.
- 게임 시작 전에 개인정보가 아닌 게임 닉네임을 입력한다.
- 포만도 100까지 걸린 시간을 측정하고, 완주 기록과 상위 10개 기록을 보여 준다.

## 3. 화면 구성

게임 전체 영역은 브라우저 안에서 **1024 × 768 이하**로 표시하며, 기본 크기는 **960 × 720**으로 한다. 브라우저 창이 더 작으면 화면 비율을 유지하면서 축소한다.

1. **상단 정보 영역**
   - 게임 제목
   - 현재 포만도 숫자와 포만도 막대(0~100)
   - 남은 공 목숨 3개
   - 게임 시작 후 경과 시간(0.1초 단위)
   - 안내 문구 또는 게임 상태
2. **중앙 게임 영역**
   - 7층 벽돌
   - 움직이는 공
   - 벽돌에서 떨어지는 먹이
3. **하단 플레이 영역**
   - 좌우로 달리는 고양이 캐릭터
   - 시작 전 조작 안내
4. **상태 알림 창**
   - 닉네임 입력, 시작 전, 승리, 게임 오버 상태를 게임 영역 위에 표시
   - 승리 또는 게임 오버 뒤 재시작 버튼과 스페이스바 안내 표시
5. **기록 영역**
   - 현재 도전자의 닉네임 표시
   - 완주 시간이 가장 짧은 상위 10개 기록 표시
   - 브라우저에 저장된 전체 완주 기록을 최신순으로 표시

## 4. 게임 진행 규칙

### 4.1 시작

- 처음 화면에는 게임 닉네임 입력란을 표시한다.
- 닉네임은 1~10글자로 입력하며 실제 이름이나 개인정보 대신 별명을 사용한다.
- 닉네임을 입력하지 않으면 게임을 시작할 수 없다.
- 닉네임을 확정하면 `스페이스키를 눌러 시작하세요!`를 표시한다.
- 스페이스키를 처음 누르면 공이 고양이 위에서 비스듬히 출발한다.
- 최초 공이 출발하는 순간부터 시간을 측정한다.
- 시작 전에는 공, 벽돌, 먹이, 포만도가 움직이거나 변하지 않는다.

### 4.2 고양이 조작

- 키보드의 **왼쪽/오른쪽 방향키** 또는 **A/D 키**로 고양이를 움직인다.
- 키를 누르고 있는 동안 고양이가 해당 방향으로 계속 달린다.
- 고양이는 게임 영역 밖으로 나갈 수 없다.
- 이동 방향에 따라 고양이 캐릭터가 바라보는 방향을 바꾼다.
- 고양이가 달릴 때 네 발이 두 쌍으로 번갈아 앞뒤로 움직이고, 발을 드는 동작을 표현한다.

### 4.3 공과 벽돌

- 공은 벽, 천장, 벽돌, 고양이에 닿으면 반대 방향으로 튕긴다.
- 고양이의 중앙과 가장자리 중 어디에 닿았는지에 따라 공의 튕기는 각도가 달라진다.
- 벽돌은 **7층**으로 배치하며, 한 층에 **10개**, 총 **70개**를 기본값으로 한다.
- 일반 벽돌은 공에 한 번 맞으면 부서진다.
- 공이 화면 아래로 떨어지면 목숨이 1개 줄고, 남은 목숨이 있으면 공이 고양이 위에서 다시 대기한다.
- 다시 스페이스키를 누르면 다음 공이 출발한다.

### 4.4 먹이와 포만도

- 모든 벽돌에는 사료, 츄르, 간식 중 하나가 들어 있다.
- 벽돌이 부서지면 먹이가 아래로 떨어진다.
- 고양이와 먹이가 닿으면 고양이가 먹고, 먹이는 사라지며 포만도가 오른다.
- 받지 못하고 화면 아래로 떨어진 먹이는 사라지며 포만도는 오르지 않는다.
- 포만도는 100을 넘지 않도록 최대 100으로 제한한다.

| 먹이 종류 | 등장 비율 | 포만도 증가 | 시각 표현 |
|---|---:|---:|---|
| 고양이 사료 | 50% | +5 | 갈색 사료 알갱이 또는 사료 그릇 |
| 간식 | 30% | +10 | 생선 또는 쿠키 모양 |
| 츄르 | 20% | +20 | 막대형 포장 간식 |

- 벽돌 70개의 먹이 구성은 확률에 따라 정하되, 한 게임 안에서 포만도 총합이 100보다 충분히 크도록 생성한다.
- 먹이를 먹을 때 짧은 냠냠 효과와 증가한 포만도(예: `+10`)를 표시한다.

### 4.5 승리와 실패

- **승리:** 포만도가 100이 되는 즉시 게임 움직임을 멈추고 `배불러요! 게임 성공!`을 표시한다.
- 승리하면 측정을 멈추고 닉네임, 완주 시간, 기록 시각을 저장한다.
- **게임 오버:** 목숨 3개를 모두 잃고 포만도가 100보다 낮으면 게임을 종료한다.
- 벽돌을 모두 부쉈지만 포만도가 100보다 낮고 화면에 남은 먹이도 없으면 게임 오버로 처리한다.
- 승리 또는 게임 오버 화면의 `다시 하기` 버튼을 누르거나 스페이스바를 누르면 같은 닉네임으로 즉시 다시 시작한다.
- 다시 시작하면 포만도, 목숨, 벽돌, 먹이, 공, 경과 시간을 처음 상태로 되돌린다.

### 4.6 시간과 기록

- 시간은 첫 공이 출발하는 순간부터 포만도 100을 달성하는 순간까지 측정한다.
- 공을 놓쳐 다음 공을 기다리는 시간도 전체 진행 시간에 포함한다.
- 화면에는 시간을 0.1초 단위로 표시한다.
- 승리한 게임만 완주 기록으로 저장하며 게임 오버 기록은 저장하지 않는다.
- 모든 완주 기록은 브라우저의 `localStorage`에 계속 저장한다.
- 전체 기록은 가장 최근 기록부터 표시한다.
- 상위 10개는 전체 기록을 완주 시간이 짧은 순서로 정렬한 뒤 앞의 10개를 표시한다.
- 기록은 현재 브라우저에만 남으며 브라우저 데이터를 삭제하면 함께 사라진다.

## 5. 시각 및 소리 연출

### 5.1 디자인

- 배경은 하늘색, 크림색, 분홍색, 연보라색이 섞인 화려한 파스텔 색상을 사용한다.
- 벽돌 7개 층은 분홍, 살구, 노랑, 민트, 하늘, 보라 계열의 서로 다른 파스텔색으로 구분한다.
- 포만도 막대와 버튼에도 여러 파스텔색의 그라데이션을 사용한다.
- 벽돌은 고양이 발바닥, 털실, 생선 무늬가 들어간 둥근 사각형으로 표현한다.
- 고양이는 CSS 도형 또는 간단한 이모지/문자 기반 그림으로 구현하여 외부 이미지 서비스에 의존하지 않는다.
- 버튼과 정보 창은 모서리를 둥글게 하고, 글자는 1024 × 768 화면에서 쉽게 읽을 수 있는 크기로 만든다.

### 5.2 애니메이션

- 고양이가 이동할 때 네 발이 번갈아 움직이고 몸이 위아래로 흔들리는 달리기 느낌을 준다.
- 공이 고양이에게 닿으면 고양이가 짧게 통통 튀는 반응을 보인다.
- 벽돌이 부서질 때 작은 별 또는 발바닥 입자가 퍼지는 효과를 준다.
- 먹이를 먹으면 고양이 주변에 하트가 잠깐 나타난다.
- 포만도 100을 달성하면 고양이가 크기 변화, 좌우 회전, 점프, 바닥 그림자 변화로 입체적인 애교를 부린다.
- 승리 애교에는 앞발 흔들기, 꼬리 움직임, 감은 눈, 발그레한 볼, 하트와 말풍선을 포함한다.

### 5.3 소리

- 첫 제작 단계에서는 별도의 음원 파일 없이 동작하는 것을 기본으로 한다.
- 공 튕김, 벽돌 파괴, 먹이 획득 소리는 브라우저의 Web Audio API로 짧고 부드럽게 생성할 수 있다.
- 소리를 넣을 경우 음소거 버튼을 제공한다.

## 6. 상태와 데이터

JavaScript에서 다음 상태를 관리한다.

- 게임 상태: 닉네임 입력, 시작 전, 진행 중, 공 재대기, 승리, 게임 오버
- 현재 도전자의 게임 닉네임
- 고양이 위치와 이동 방향
- 공의 위치, 이동 방향, 속도
- 벽돌별 위치, 파괴 여부, 들어 있는 먹이 종류
- 떨어지는 먹이의 위치와 종류
- 현재 포만도(0~100)
- 남은 목숨(초기값 3)
- 게임 시작 시각과 경과 시간
- 완주 기록 목록(닉네임, 완주 시간, 기록 시각)

닉네임 입력란에는 실제 사람의 이름, 학번, 이메일, 전화번호 등 개인정보를 입력하지 않도록 안내한다. 기록은 서버로 전송하지 않고 현재 브라우저의 `localStorage`에만 저장한다. 외부 서비스, 비밀키, 비밀번호, 토큰은 사용하지 않는다.

- 선택 사항인 효과음과 음소거 기능
- 다양한 브라우저 크기에서 화면 확인

### 4단계: 사용자와 기록 기능

- 게임 시작 전 닉네임 입력과 검사
- 첫 공 출발부터 승리까지 0.1초 단위 시간 측정
- 브라우저에 전체 완주 기록 저장
- 상위 10개와 전체 기록을 화면에 함께 표시

> 프로그램 제작 요청이 단계별로 주어지면 요청받은 단계만 진행한다.

## 10. 제작 전 확인을 권장하는 선택 사항

아래 항목은 현재 기획서에서 괄호 안의 값으로 기본 확정했으며, 제작 전에 원하면 바꿀 수 있다.

1. 한 층의 벽돌 개수 (**10개, 총 70개**)
2. 고양이 조작 키 (**방향키와 A/D 모두 지원**)
3. 공을 놓칠 수 있는 횟수 (**목숨 3개**)
4. 먹이를 놓쳤을 때 처리 (**먹이는 사라지고 포만도는 오르지 않음**)
5. 승리 조건 (**벽돌을 모두 제거하는 것보다 포만도 100 달성을 우선**)
6. 고양이와 먹이 그림 방식 (**외부 이미지 없이 Canvas 도형과 이모지 중심**)
7. 효과음 (**Web Audio API 효과음과 음소거 버튼을 3단계에서 추가**)
8. 사용자 식별 방식 (**실제 이름이 아닌 최대 10글자의 게임 닉네임**)
9. 시간 측정 범위 (**첫 공 출발부터 포만도 100 달성까지, 공 재대기 시간 포함**)
10. 기록 저장 위치 (**서버가 아닌 현재 브라우저의 localStorage**)
